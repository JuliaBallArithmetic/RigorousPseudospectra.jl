*Method.* The sweep is tiered cheapest-first: the cheap scalar floors (free triangular gap, SVD-frame, recentred) with the resolvent maximum principle on eigenvalue-free cells, then — only where those are inconclusive — escalation to the **block/cluster tier** (`gap_cluster`, a tight per-z verified-SVD bound on each coupling-graph cluster, built once and cached). The `routing` column shows which tier settled each excluded cell: normal matrices resolve entirely on `triangular`; strongly non-normal / clustered ones (`grcar`, `jordan`, `two_clusters`) escalate to `cluster`. Either way the result is a thin certified contour bracketing the true level set.
